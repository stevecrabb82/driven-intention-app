# Driven Intention

A working prototype for a 90-day goal and execution system.

## Current features

- Create, edit, and delete 90-day goals
- Business, Health & Fitness, Financial, and Personal categories
- Add, edit, delete, and complete priorities
- Goal progress slider
- Execution score based on completed priorities
- Motivational mindset prompts
- Local browser persistence so goals remain after refresh
- Responsive layout for laptop and phone

## Run locally

1. Install Node.js.
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL Vite displays.
